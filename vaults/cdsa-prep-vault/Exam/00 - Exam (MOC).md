# Exam

Your workspace for exam days: incidents, IOCs, flags and a log for each day. Every table here matches a part of the [official CDSA report template](https://docs.sysreptor.com/assets/reports/HTB-CDSA-Report.pdf), so by the end most of the report is already written down.

> [!danger] Keep this vault private
> Once you start the exam, this vault holds exam content. Don't push it to a public GitHub repo or share it, during or after the exam. HTB's terms don't allow it.

## Start here
1. [[01 - Before You Start]]: go through the checklist before you start.
2. [[02 - Scope & Rules]]: copy the scope from the letter of engagement.
3. Keep a log as you work: `Log/` has one note per exam day, from [[Day 01]] to [[Day 07]].

## Incidents
One note per item in `Incidents/`. Start with [[Incident 1]] and rename it. For each new one, create a note in `Exam/Incidents`, then run **Insert template → Incident**.
