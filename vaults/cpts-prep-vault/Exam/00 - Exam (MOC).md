# Exam

Your workspace for exam days: targets, credentials, findings, flags and a log for each day. Every table here matches a part of the [official CPTS report template](https://docs.sysreptor.com/assets/reports/HTB-CPTS-Report.pdf), so by the end most of the report is already written down.

> [!danger] Keep this vault private
> Once you start the exam, this vault holds exam content. Don't push it to a public GitHub repo or share it, during or after the exam. HTB's terms don't allow it.

## Start here
1. [[01 - Before You Start]]: go through the checklist before you start.
2. [[02 - Scope & Rules]]: copy the scope from the letter of engagement.
3. Keep a log as you work: `Log/` has one note per exam day, from [[Day 01]] to [[Day 10]].

## Targets
One note per item in `Targets/`. Start with [[Target 1]] and rename it. For each new one, create a note in `Exam/Targets`, then run **Insert template → Target**.

## Tracking
- [[03 - Network Map]]: how the networks connect, and your tunnels.
- [[04 - Credentials]]: every user and secret you find. Report: *Compromised Users*.
- [[05 - Findings]]: every vulnerability worth reporting. Report: *Summary of Findings*.
- [[06 - Attack Chain]]: the path through the network, step by step.
- [[07 - Flags]]: every flag and where it came from. Report: *Flags Discovered*.
- [[08 - Cleanup]]: everything you changed on a host. Report: *Changes/Host Cleanup*.
