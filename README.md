# Study Trackers

Interactive, single-file day-by-day study trackers for Hack The Box certifications, one folder per cert. Open the hosted page to pick a tracker, or open any `<code>/index.html` directly in a browser.

Each tracker is a self-contained HTML file: adjustable timeline, progress dashboard, and a curated resource library. Progress saves to your browser's localStorage, separately per tracker.

This is a test consolidation of the individual per-cert repositories.

Built on [mattrfield's coae-study-tracker](https://github.com/mattrfield/coae-study-tracker), the original inspiration for this project.
